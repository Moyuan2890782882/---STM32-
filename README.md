# ---STM32-
毕业设计
基于STM32F103的智能拐杖设计
以STM32F103C8T6单片机为核心控制单元，集成多种传感器模块与通信模块。利用光敏电阻模块检测光照强度，光照不足时通过LED模块进行补光；采用超声波模块测量前方距离，异常时蜂鸣器预警；运用姿态传感器监测老人姿态，跌倒时语音预警并发送短信，同时支持手动按键取消误报；借助温度模块与心率模块分别监测老人实时的体温和心率，异常时发送短信报警；设置按键可修改阈值，实现一键报警与取消报警操作；通过OLED显示屏实时显示温度、距离、心率、光照强度等数据；采用通信模块在报警时向手机端发送短信。
